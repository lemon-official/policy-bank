# Brand guidelines

> Placeholder: brand owns this file. Replace the rules below with the real guidelines and keep
> each rule short, testable and numbered so specs can cite it (for example `BRAND-3`).

## Rules

1. **BRAND-1 Product names.** Use the official product names exactly as written in the
   name list. Never abbreviate them in customer-facing text.
2. **BRAND-2 Voice.** Plain, direct, friendly. Second person ("you"), active voice, no jargon.
3. **BRAND-3 Visual identity.** Colours, type and logo usage come from the design system only;
   no new colours or fonts in feature work.

## How to apply

- In a spec, list every customer-visible surface the change touches and the rules that apply.
- If a requirement can't meet a rule, raise it as a flagged concern with `policy_owner: brand`.
  Don't silently work around it.
